Samsung refrigerator error codes

What the codes on a Samsung fridge display mean, which ones you can try to clear yourself, and which ones need a technician. This page follows Samsung’s own published lists and leaves out anything Samsung does not document.

Codes differ by model and region

Samsung does not use one universal code set. The same code can mean different things, or not exist, depending on the model line and the country. Samsung’s Canadian page says its list does not cover every code, and we did not find a mapping to specific models. Read the code on your display, then confirm it against the manual for your model number. Samsung Turkey publishes a different format, covered in its own section below.

Before you touch anything

  • Unplug the fridge before you touch any component, wiring or the harness.
  • Do not unplug the fridge or press panel buttons to clear a code unless the steps for that code say so. Samsung warns this can hide the fault from the technician.

Samsung Turkey codes (E08 to E11)

Family Hub Self Check

This is the only self-diagnosis Samsung documents for owners. On a Family Hub fridge, go to Apps, then Fridge Manager, then Fridge Settings, then Self Check, then Start. It lists current and past codes, which is useful to read out to a technician. Non-Family Hub models have no official owner-facing equivalent that we could verify.

When to call service

  • A code in the table above says service, or the suggested steps did not clear it.
  • A fan, voltage or compressor code returns after you have cut power once.
  • Any code that is not listed. Samsung’s advice is to request service.

Beyond the fix

Did you knowFor 21E, Samsung says the electronics are not sensing the freezer fan turning. Frost from an open door or gasket gap is the usual cause, with a failed motor also possible.

Tips and tricks

  • Check the door gaskets seal all the way round, and do not pack the fridge so full that doors cannot close.manufacturer manual
  • To check a fan, one video films the compartment with a phone light, closes the door, then reopens it to look for airflow.technician video
  • A showroom Cooling Off message is not a fault. One video says the exit buttons differ by display type.technician video

Common mistakes

  • Unplugging for any code. Samsung says to do so only where the steps say so, such as 60 seconds for power codes.

Easily confused with

  • 21E is the freezer fan and 22E is the fridge fan per Samsung. Some videos label 22E differently, so check the Samsung table.

Questions

Do all Samsung refrigerators use the same error codes?

No. Codes differ by model line and by region. The table above comes from Samsung support pages for the US and Canada, and Samsung Turkey uses a different set. Samsung’s Canadian page also says its list is not complete, so check your manual for your model number.

Should I unplug my Samsung fridge when a code appears?

Only if the steps for that code say to. Samsung advises against unplugging or pressing panel buttons to clear a code otherwise, because it can make the technician’s diagnosis harder. Where a code does call for a power cycle, such as 22E or 88 88, follow the timing in the table.

Is there a way to run a self-diagnosis on a Samsung refrigerator?

Samsung documents one for owners: the Self Check on Family Hub models. Open Apps, then Fridge Manager, then Fridge Settings, then Self Check, then Start. It shows current and past codes. A technician-only service mode exists, so we do not list it.

What if my code is not on this page?

Samsung’s guidance for any code not on its list is to request service. Contact Samsung support or an authorized technician.
