De'Longhi Magnifica / Dinamica Descale light stays on after descaling: descale will not clear

Descale light stays on after descaling means: Descale cycle not registered as complete.

Short answer. The machine only clears the descale reminder when it sees a full descale cycle including the rinse phase, run from the descale menu with the spout fitted. Stopping early, running it manually, or a water-filter setting that is wrong leaves the light on.
Part at faultdescale counter / flow sensor
Severitylow
DIY difficultyeasy
When it appearsany

How to fix Descale light stays on after descaling

  1. Run the descale from the menu (not just by pouring descaler in), with the spout fitted and a large bowl, and let both phases finish.
  2. Check the water-filter setting matches whether a filter is fitted.
  3. If it still stays on, the flow sensor is scaled and not counting; run a second descale.

When to stop and call a repairer

Nothing dangerous here.
