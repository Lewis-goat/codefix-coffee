Insert Grounds Container / Empty Grounds ContainerDe'Longhi

De'Longhi Magnifica / Dinamica Insert Grounds Container / Empty Grounds Container: grounds container not detected

Insert Grounds Container / Empty Grounds Container means: Grounds container not detected, or the empty message will not clear.

Short answerThe container is detected by a switch or contacts behind it. Wet grounds, coffee sludge or scale on those contacts, or a container not pushed fully home, gives a false reading. The empty-grounds counter only resets when the machine sees the container removed for a few seconds.
Part at faultgrounds container switch and contacts
Severitylow
DIY difficultyeasy
When it appearsany

How to fix Insert Grounds Container / Empty Grounds Container

  1. Switch off. Remove the drip tray and grounds container together.
  2. Clean the container and the area behind it, and wipe the metal contacts or switch with a dry cloth.
  3. Leave the container out for at least ten seconds (to reset the counter), then refit firmly.
  4. If the message stays, the switch has failed; it is cheap but inside the machine.

When to stop and call a repairer

Nothing dangerous here.
