Jura Error 4: steam thermoblock overheat

Error 4 means: Steam thermoblock overheating or a defective sensor.

Short answerThe steam thermoblock got hotter than the board expected. Either the sensor is under-reading (scale insulation, corroded contacts) or the power board did not cut the heater. Jura lists Errors 2 and 4 as the two most common repairs.
Part at faultsteam thermoblock NTC sensor / power board
Severityhigh
DIY difficultyhard
When it appearsany

How to fix Error 4

  1. Unplug and let the machine cool for an hour.
  2. Run a full descale. Scale on the thermoblock changes how quickly the sensor sees heat.
  3. Inspect the sensor cable and contacts for corrosion; replace the NTC.
  4. If it overheats again with a new sensor, the power board is not switching the heater off and must be replaced.

When to stop and call a repairer

A heater that will not switch off is a fire risk. Do not leave the machine powered unattended while this code is active.

Questions

What does Error 4 mean on the Jura?

Steam thermoblock overheating or a defective sensor. The steam thermoblock got hotter than the board expected. Either the sensor is under-reading (scale insulation, corroded contacts) or the power board did not cut the heater. Jura lists Errors 2 and 4 as the two most common repairs.

When does Error 4 typically show up?

Juras report Error 4 any. That timing is a useful clue when narrowing the cause.

Can I keep using the machine with Error 4 showing?

Treat it as a stop-using signal: Error 4 marks a fault that can damage the machine (or worse) if you keep running it. Do the safe first steps below, then stop.

Will Error 4 clear on its own?

Rarely. A reset or power cycle is worth one try, but Error 4 with a "hard" difficulty rating almost always means a failed component that has to be replaced.

How long does the repair take?

This one is a bench repair for most owners — the teardown, test and reassembly are the bulk of the work, not the part itself.
