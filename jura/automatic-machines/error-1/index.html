Jura Error 1: thermoblock sensor fault

Error 1 means: Coffee thermoblock temperature sensor fault (S/X/J/Z family); damaged sensor on F/E80.

Short answer. The control board cannot get a sane reading from the temperature sensor on the coffee thermoblock. A cold machine straight from a cold car or garage can trigger it; otherwise the sensor, its cable, or the thermal-fuse cords that feed the thermoblock have failed.
Part at faultcoffee thermoblock NTC sensor
Severitymedium
DIY difficultyhard
When it appearsany

How to fix Error 1

  1. Unplug for five minutes, let the machine sit at room temperature for an hour if it has been cold, and restart.
  2. If it clears, it was temperature. If it returns instantly on a warm machine, the sensor circuit is open.
  3. Opening a Jura needs the oval-head (Torx-Plus security) driver. With the cover off, check the sensor plug on the thermoblock and the thermal-fuse cords for a broken link.
  4. Replace the NTC sensor (cheap) and the fuse cords together; if the thermoblock itself is scaled solid, replace it.

When to stop and call a repairer

Jura cases are held with security screws and the thermoblocks carry mains voltage. If you are not set up for that, this is a bench repair.

What it costs

Parts: Genuine Jura NTC sensor about $25 to $40; thermal-fuse cord set $15 to $30; a thermoblock $90 to $180.

Service: Out-of-warranty manufacturer service for a super-automatic is typically $250 to $500 including return shipping; independent espresso repairers are usually cheaper for a single part.

Worth repairing? Yes on S, Z, GIGA and newer E-series; on a 10-year-old Impressa weigh the quote against a refurbished unit.
