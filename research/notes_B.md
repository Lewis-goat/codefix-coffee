# SERP notes — B candidates (scored 2026-09-02)

Method: WebSearch on 3–5 seed queries per niche; judged by who ranks in the top ~8, page age/thinness, whether a tool already owns the query, and whether an AI Overview would fully answer it. Skeptical baseline: in 2026 nearly every "X calculator" query already has 5+ calculators, many of them freshly AI-generated farms.

---

## B1 — 3D-printer cost calculators — 27/40
**Queries run:** 3d printer cost calculator; 3d printer electricity cost calculator; 3d print filament cost per gram; resin printer cost per print; 3d printer cost to run per hour
- *cost calculator*: 3dwithus, printpal.io, omnicalculator (#4), 3dfils, 3dprintforce, 3dprintingcostcalculator.com, 3dprintpricecalculator.com, makershop, a Play Store app. Nine calculators, none a big publisher.
- *electricity cost calculator*: 3dwithus, 3dsourced, sovol3d blog, calculop, sanix3d, pea3d (per-Elegoo-model pages), spoolmath. Small/new sites everywhere.
- *filament cost per gram*: snapmaker/qidi/3dfuel manufacturer blogs, omni, spoolmath, 3dfilamentprice.com, a .edu libguide (weak signal).
- *resin cost per print*: resinprinters.org, 3dsolved, completecalculators, resincalc.com, 3dprintbounty — all small.
- *cost to run per hour*: manufacturer blogs (Raise3D, Flashforge, Qidi, Snapmaker, Eufy) + layers.app. Pure informational, AIO answers it ("$0.05–0.15/hr").
- **Weak signals:** small/new sites, .edu page, no major media. **But** the calculator itself is commoditised (omni + ~10 clones).
- **Gap:** per-printer-model pages ("Bambu A1 electricity cost", "Prusa MK4 cost per hour") with measured wattage tables — pea3d does Elegoo only; spoolmath has presets but no per-model landing pages.

**Queries run:** aquarium dosing calculator; aquarium ammonia dosing calculator fishless cycle; aquarium water change calculator; aquarium salt dosage calculator; planted tank fertilizer calculator
- *dosing calculator*: API Fishcare (#1, #3), BRS, Seachem, teracalculators, 2hraquarist, aquariummath.com, aquarian, dosemytank.com, Red Sea. Brands own the top 3.
- *ammonia fishless cycle*: natureaquariums (shop), **fishlore forum #2**, freshwateraquariumservices.co.uk, aquajocund, fishtankcalc.com, spec-tanks, fishtankmath.com. Mostly tiny/new sites.
- *water change calculator*: **fishlore forum #1**, reefexclusive, hamzasreef (old, x2), beananimal, aquariumcalc.com, **reef2reef forum**, an iOS app. Very weak.
- *salt dosage*: Waterbox, Top Shelf, BRS, aqulator, interpet, calculatorshub.net, calculator.academy (farm), hamzasreef, API.
- *fertilizer calculator*: barrreport (forum-hosted tool), scapecrunch (forum x2), paullefevre.com/ifc (Excel), plantsolve, aquariumlesson, greenleafaquariums, rotalabutterfly (classic old tool).
- **Weak signals:** forums in top 5 on 2 of 5 queries, decade-old hobbyist tools (hamzasreef, rotalabutterfly), and a swarm of 2025–26 AI-built calculator sites (aquariummath, fishtankmath, fishtankcalc, aquajocund) — i.e. low bar, but the "build a clean calculator hub" move has already been made 4x this year.
- **Ad value is the problem:** pet-supply CPCs are low; the $1.25/mo target would need ~1.5–3k pageviews/mo.
- **Gap:** product-specific dosing pages (brand x product x tank size) — dosemytank does Seachem/API/Fritz/eSHa already, so gap is narrow.

## B3 — Reloading / ammunition calculators — 23/40 (soft DQ: ad-policy)
**Queries run:** reloading cost calculator; grains to grams calculator; powder charge weight calculator; bullet drop calculator; (reloading cost per round overlaps #1)
- *reloading cost calculator*: Dillon (manufacturer), ultimatereloader, actiongunner, MEC, **losttarget.com/costcal.htm (1990s-style page)**, x-reload, **enoughgun forum (Excel thread)**, ecsc-skeet, shootersreference, eBay. Very weak SERP.
- *grains to grams*: convertunits, metric-conversions, unitconverters.net, kylesconverter, convert.app — unit-converter giants; unwinnable, skip.
- *powder charge weight calculator*: Dillon, **accurateshooter forum**, **kwk.us/powley.html (ancient)**, shootingsoftware.com, Wikipedia, **thefiringline forum**, rocketry site, **a PDF from a gun club**. Extremely weak — but no clear intent (query is ambiguous).
- *bullet drop*: shooterscalculator, Play/App Store apps, Caldwell, Wikipedia, Berger, Lapua, Federal, Hornady 4DOF, ballisticapp. Manufacturer-owned; skip.
- **Weak signals:** forums, PDFs, 20-yr-old pages — strongest raw SERP weakness in set B after B5.
- **Killer issue:** firearms/ammunition is restricted or banned on AdSense and most display networks; affiliate options (Brownells etc.) exist but the site's stated goal is ad revenue. Powder-charge guidance also carries safety liability (not a rubric YMYL DQ, but adjacent).
- **Gap if pursued:** per-caliber cost-per-round pages with live component pricing — actiongunner already partially does this.

## B5 — Espresso-machine error-code lookup by brand — 29/40
**Queries run:** breville espresso error code er05; delonghi espresso error codes; jura error 8; saeco error codes; breville barista pro not working
- *breville er05*: **JustAnswer x5** + homecoffeemachines.ie shop blog. No official Breville page ranks. Textbook under-served SERP.
- *delonghi error codes*: mycoffeemachine.co.uk (shop), **Fixya**, coffeefixhub.com (small), **fault-codes.jimdofree.com** (free-host site), then **3 eBay listings**. Garbage SERP.
- *jura error 8*: caffe-select.co.uk (shop), **JustAnswer x3**, jura-parts.com (x2), **bean2cup.org forum**.
- *saeco error codes*: **manualslib scans x2**, partstown, saeco.com FAQ (the one official page), coffeegrump, baristalife, **Fixya**, kanencoffee, osoappliance.
- *barista pro not working*: **Breville PDF manual**, **JustAnswer x3**, then **5 eBay/slickdeals listings**. Google clearly has nothing good to show.
- **Weak signals:** JustAnswer/Fixya/manualslib/jimdo/eBay on every query; parts shops rank because nobody else bothered. 3+ weak signals on all 5 queries → 5/5.
- **AIO caveat (why only 2/5):** "what does Jura error 8 mean" is answered in one sentence and AIO already synthesises these shop pages. Clicks that survive: step-by-step fix guides with photos, part numbers, "is it worth repairing" and model-specific nuance. Structure pages around the fix, not the definition.
- **Gap:** no brand-agnostic, clean, structured error-code database exists (brand → model → code → cause → DIY fix → part → cost). Every incumbent is a parts shop, a paywalled Q&A, or a scanned manual. Programmatic: ~6 brands x 10–40 codes each = 150+ pages from one template, plus "X not working" hubs.

## B7 — Sim-racing setup calculators & per-car tables — 31/40 (best in set B)
**Queries run:** sim racing fov calculator; iracing fov calculator; sim racing wheel rotation per car; sim racing ffb settings table
- *FOV calculator*: apexsimracing blog, simracingcockpit.gg, mysimrig.nl, sampsoid, ocracing, simcoaches, simracing-pro, **dinex86.github.io** (GitHub Pages app). Eight small sites, zero big media — but eight calculators = saturated sub-topic. Don't lead with FOV.
- *iracing fov*: same set + **jscalc.io page** + fovcalc.app. Same conclusion.
- *wheel rotation per car*: **overtake.gg forum x2**, **Wikipedia x2**, **Steam discussions x3**, **GitHub repo (Havner/acc-steering-lock)**. Eight results, zero purpose-built pages. This is the clearest unowned query in the entire B set.
- *ffb settings table*: **Fandom wiki** (ancient Simbin guide), simracingcockpit.gg, simracingsetup.com, racingnear.me, gitgudracingacademy, ocracing FFB calc. Small guide sites; no structured cross-sim x cross-wheelbase matrix.
- **Weak signals:** forum/Steam/GitHub/Wikipedia/Fandom on 2 of 4 queries; small affiliate blogs on the rest.
- **AIO:** per-car steering lock and per-wheelbase FFB values are tables that change per game patch and per hardware — an AI summary can't hold 200 car x sim combinations reliably; FOV needs the user's measurements.
- **Ad value:** direct-drive bases, load-cell pedals, cockpits ($300–2,000) — strong affiliate + high CPC.
- **Personal edge:** owner's 3D/game-engine background covers FOV/projection math and camera models; software skills allow scraping steering-lock values directly from sim data files (AC/ACC car.ini, rF2, iRacing) to build the table programmatically rather than by hand.
- **Gap (build this):** `/{sim}/{car}/steering-lock` + `/{wheelbase}/{sim}/ffb` matrix, plus one FOV calc as a supporting tool. Data source: sim config files + community-verified values from the very forum threads that currently rank.

## B9 — Mechanical keyboard reference — 29/40
**Queries run:** mechanical keyboard switch comparison chart; keycap sizes chart; 65 vs 75 keyboard layout; keyboard switch actuation force table
- *switch comparison chart*: **KeebTalk forum #1 and #2**, RTINGS compare tool (big), thegamingsetup, gomk, keeb-finder (700+ DB), kordu.tools, keybumps (530+ DB). Forum on top, but three switch databases already exist.
- *keycap sizes*: Keychron (K2-specific), hirosarts, Omnitype (x2), minimaldesksetups, maxkeyboard (old classic chart), deskfinds, **printables.com models x2**. Vendor + hobby sites.
- *65 vs 75*: Keychron, hirosarts, Angry Miao, Attack Shark, MelGeek, mkbguide — 100% vendor content; AIO fully answers it. Skip comparison essays.
- *actuation force table*: **telcontar.net (old hobbyist page) #1**, Glorious, KeebsForAll, digitec, thegamingsetup, metal-domes, keyblink, keyboardcapers. Weak, but vendors present.
- **Weak signals:** forum #1, 2000s hobbyist page #1, printables models ranking. Meaningful.
- **KD reality:** RTINGS + Keychron + 3 dedicated switch DBs; you'd be 4th switch DB. Not attractive on the switch side.
- **Gap:** per-keyboard-model keycap compatibility ("what keycap set fits the NuPhy Air75 / Keychron Q1 / Lofree Flow") — Keychron does it only for its own boards, and low-profile/non-standard bottom rows are the #1 buyer confusion. Programmatic: board → layout → stem type → keycap sizes needed → compatible sets (affiliate). High ad/affiliate value.
