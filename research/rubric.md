# Scoring rubric (0-5 each, 8 criteria, max 40)
1. SERP weakness: run 3-5 seed queries via web search. Weak signals = Reddit/Quora/forum/GitHub issue in top 5, PDFs/.edu, 5+yr-old pages, title not matching query, thin pages, low-authority sites. 5 = 3+ weak signals on most queries; 0 = big publishers own top 10.
2. Keyword difficulty (estimate from SERP authority): 5 = mostly small sites/forums; 0 = Wikipedia/major brands/big media dominate.
3. Cluster search volume (estimate; use autocomplete breadth + how many distinct long-tail queries exist): 5 = 2k-20k/mo cluster; 0 = <300/mo.
4. AI-Overview resistance: 5 = query needs a tool/table/interactive thing an AI summary can't replace; 0 = a one-sentence AI answer fully satisfies it.
5. Ad value: 5 = tech/gear/software niches with CPC >$1.50; 0 = CPC <$0.20 (pure curiosity/kids/memes).
6. Content leverage: 5 = one template yields 50+ pages (programmatic/calculator); 0 = each page is a bespoke 2k-word essay.
7. Personal edge for the site owner (deep first-hand knowledge of: Pine Script/TradingView, Three.js/browser game dev, voxel engines, prediction-market mechanics, hypertrophy training, GeoGuessr; general strong software skills): 5 = deep expertise; 0 = none.
8. Longevity: 5 = evergreen/rising; 0 = fad/declining.
Hard disqualifiers: YMYL (health/medical advice, personal finance/investing advice, legal, gambling advice) -> note DQ.
