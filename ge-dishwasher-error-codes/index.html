GE dishwasher error codes

What each code means, which ones GE actually documents, and which meanings are only owner-reported. Every code links to its own fix-first page.

Codes GE documents

GE publishes a code table on its support site (see sources below). It says not all codes appear on all models. These are the definitions it gives:

Codes GE does not document

  • CFE: not in GE’s public table. A service-manual citation for CDT-series (2020 plastic-tub) models says Continuous Fill Error. Treat it as a fill problem first.
  • 888: not in GE’s public table. Owners and repair forums link it to the control board. Confirm the diagnosis before buying a board.
  • E1: GE shows LEAK DETECTED on many models; “E1” is an owner-reported label for the same leak fault.

Resetting a GE dishwasher

GE’s steps: press Start/Reset, wait two minutes, then switch the dishwasher off at the breaker for about 30 seconds and restore power. That involves your home’s mains supply, so keep hands out of the machine while power is on. Many drain and fill codes clear with this reset and the cleaning steps on each code’s page.

Diagnostic mode

GE does not publish a consumer diagnostic-mode sequence. Service-mode entry differs by model and is in the technical service manual for your model number. Sequences posted online are model-specific, and service mode can run pumps, valves and heaters, so we leave them out.

Questions

What does CFE mean on a GE dishwasher?

GE does not list CFE in its public code table. A parts site citing the GE service manual for the 2020 plastic-tub series (CDT-prefix models) defines it as Continuous Fill Error, meaning the tub kept filling. Other sites call it a communication fault; we could not confirm that against a GE document, so check the fill first.

How do I reset a GE dishwasher?

GE’s own guidance: press Start/Reset, wait two minutes, then switch the dishwasher off at the breaker for about 30 seconds and restore power. A separate 999 reset (hold Cycle Select and Start for about five seconds) is documented only for a few models.

How do I enter diagnostic mode on a GE dishwasher?

GE does not publish a consumer sequence. Entry differs by model and is in the technical service manual for your model number. Button sequences found on forums are model-specific, often wrong, and service mode can run pumps, valves and heaters, so we do not list them.

Do all GE dishwashers show all of these codes?

No. GE says not every code appears on every model. Check the model number on the tub or door edge if a code does not match your machine.
